Employee applies for absence. «includes» 'Baki Layak' balance validation (Annual), «includes» MC document upload (Sick), «includes» Past overtime hours audit (Replacement/Cuti Ganti).

Branch Leader (Branch staff) or HOD (HQ staff) reviews application. «includes» Colleague Leave Clash / Overlap Warning Detection.

System automated service decrements leave balance in leave_balance_adjustments and publishes confirmed dates to company_leave_calendar.

UC-LEAVE-05: Entitlement Governance Hub

HR Admin allocates annual leave baselines, executes yearly carry-forward rollovers, and makes manual reconciliation adjustments.

2. UML Activity Diagrams (Execution Logic)

Separated Operational Workflows: Attendance Dynamic Decision Tree vs Leave Multi-Tier State Machine

Swimlane & Logic Branching

Attendance Tracking Activity Workflow

1. Mode Determination: System checks active assignments: Outstation → Temporary Branch → Multi-Location → Standard Onsite fallback.
2. Geofence Resolution:
  • Standard: Distance to Home Branch Master Coords ≤ 50m
  • Outstation: Bypass geofence + Reverse Geocoding scan
  • Temp Branch: Swap target coordinates to Temp Branch ≤ 50m
  • Multi-Location: Validate against user-picked target branch ≤ 50m
3. Biometric & Anti-Spoof Gate: Validates mock location = false, proxy = false, face verification = passed. If face fails, routes to Assisted Admin Clock-In.
4. Live Shift & Checkout: Active shift timer, live "Update Location" audit pings for outstation, shift completion recorded on Clock-Out.

Leave Tracking Activity Workflow

1. Form Submission & Rule Engine:
  • Annual/Emergency: Checks Baki Layak ≥ Requested Days
  • Sick: Validates clinic Medical Certificate attachment
  • Replacement (Cuti Ganti): Verifies historical overtime worked on off-days
2. Tier 1 Review & Clash Detection: Branch Leader or HOD inspects overlap with team members. Approves or Rejects with remarks.
3. Tier 2 Executive Signoff: Managing Director (Branch) or Operation Manager (HQ) executes final review.
4. State Finalization: On approval, automatically deducts balance in leave_balance_adjustments, inserts to company_leave_calendar, and pushes live alerts.

3. Waterfall Method SDLC Implementation

Classical sequential software engineering lifecycle applied across Attendance and Leave Tracking tracks

Sequential Engineering Model
Phase 1

Requirements Specification

Attendance Requirements: Define 50m radius threshold, GPS coordinate accuracy, mock location prevention, and the 4 operational modes.
Leave Requirements: Specify Malaysian statutory leave laws, MC upload requirements, replacement OT qualifications, and 2-tier approval hierarchy.
Phase 2

System & Database Design

Attendance Architecture: Design Haversine geofence calculation module, reverse geocoding API integration, and SSE real-time broadcasting.
Leave Architecture: Design 21-table PostgreSQL relational schema, approval state machine, and clash detection overlap algorithms.
Phase 3

Implementation & Coding

Attendance Coding: Build React mobile frontend, camera biometric feed, GPS hardware listener, and REST endpoints for clock-in/out.
Leave Coding: Develop 8 entitlement management sub-modules, leave application forms, calendar grid views, and PDF/CSV report exporter.
Phase 4

Verification & Testing

Attendance Testing: Field testing GPS coordinates at branch perimeters, verifying mock location app detection, and stress testing simultaneous clock-ins.
Leave Testing: Validate carry-forward rollover logic, verify clash warnings during concurrent team requests, and audit balance deduction accuracy.
Phase 5

Deployment & Maintenance

Operations: Deploy to Supabase cloud, calibrate branch Wi-Fi BSSID routers, and set up live supervisor monitoring dashboards.
Maintenance: Execute annual leave resets on Jan 1st, archive previous year's attendance logs, and monitor cloud database performance.

4. Running System in Production

Live runtime lifecycle, event streams, state transitions, and background daemon services

Real-Time Production Runtime

Attendance Runtime State Machine

Real-time SSE Stream
State 1: IDLE / OUTSIDE_WINDOW

Employee app checks daily company holiday calendar. If holiday, clock-in is restricted.

State 2: SENSING & VALIDATING

Hardware GPS coordinates polled. Haversine distance computed against Home, Temp, or Selected Multi-Branch. Mock location scanned.

State 3: SESSION_ACTIVE (Timer Running)

Presence pushed to Supabase attendances. Server-Sent Events (SSE) immediately increments "Present" or "Late" counter on HR Dashboard.

State 4: OUTSTATION_TRANSIT

When on outstation duty, employee triggers "Update Location" at client checkpoints, appending new GPS coordinates into employee_location_logs.

State 5: SHIFT_TERMINATED

Clock-out calculates productive working hours, break hours, and lateness penalties for payroll reconciliation.

Leave Runtime State Machine

Transactional Workflow
State 1: DRAFT_VALIDATING

Dynamic UI blocks submission unless Baki Layak ≥ days requested, MC file uploaded, or replacement hours match.

State 2: PENDING_TIER_1 (Supervisor Review)

Request locked in leave_requests. Branch Leader or HOD dashboard highlights concurrent team absence clashes.

State 3: PENDING_TIER_2 (Executive Review)

Managing Director or Operations Manager receives endorsement for final administrative signoff.

State 4: APPROVED_SYNCHRONIZED

Database transaction decrements user balance in leave_balance_adjustments and syncs record to company_leave_calendar.

State 5: MIDNIGHT_CRON_MARKER

At 00:00 daily, automated cron inspects active approved leaves and automatically tags employee attendance as "On Leave", preventing false absences.

4 Attendance Modes & Leave Flow
1. Onsite: Coordinates Scan → Geofence Check (Home ≤ 50m) → Mock Location Check → Face Verification → Check-IN Recorded.
2. Outstation: Outstation Form → HR Approval → Bypass Geofence → Reverse Geocoding → Face Auth → Check-IN → Live Location Update → Checkout.
3. Temp Branch: HR Assignment Dates → Target Geofence Swapped → Temp Coordinates Scan (≤ 50m) → Face Auth → Check-IN (Temp Status).

End-to-End Sequence Diagrams

Realtime Execution

Attendance Sequence Highlights:

1. Client requests navigator.geolocation.
2. Backend executes Haversine formula against Target Branch coordinates.
3. Anti-spoof scans detect mock location apps & Wi-Fi BSSID.
4. Face Verification runs. If failed, Assisted Check-in by Admin overrides.
5. Records saved to attendances; SSE notifies Admin Dashboard.

Leave Sequence Highlights:

1. Form validates Baki Layak, MC attachment, or past worked overtime.
2. Tier 1 Approver (Branch Leader / HOD) reviews with Clash Warnings.
3. Tier 2 Approver (Managing Director / Ops Manager) provides final corporate signoff.
4. Approved days decremented from entitlement; synced to Company Leave Calendar.
